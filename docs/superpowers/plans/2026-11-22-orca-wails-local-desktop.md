# Orca-Wails 本机桌面入口实施计划

> 依据已确认的桌面启动方案执行。每项通过回归验证后再启用生产入口。

**目标**：自管 Core 以 `local` 身份启动和重连，使用本机 IPC，普通 Web 与配对窗口继续使用原来的协议。

**结构**：Wails 管理主窗口的启动身份、进程校验和 IPC 生命周期。前端使用独立桌面入口，复用上游组件和可共用的 RPC 适配。Core 的桌面 IPC 与 CLI 共用本机传输设施，并用独立的桌面调用上下文处理事件和订阅。

## 实施

- [x] 给本机窗口建立独立启动 URL，覆盖无配对邀请、配对窗口、Core 未运行和旧 Core 的兼容行为。
- [x] macOS 接入验证过的自管进程 Unix Socket。测试调用、身份不符拒绝、流事件和取消。
- [x] 构建 macOS 桌面入口，安装本机 API，使用 `local` 归属与原生文件和终端路径。迁移已证实属于本机 Core 的旧引用和首选项。
- [ ] 验证新旧包切换、真实 Core 关闭启动配对后的桌面会话、窗口重载、Core 重启、普通浏览器与远程连接。验证打包采用独立测试 Profile。
- [ ] Windows Core 包接入桌面入口并验证 Named Pipe。
