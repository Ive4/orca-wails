# Orca-Wails macOS 菜单栏分工

这份文档记录左侧应用菜单的原始方案。当前整合后的布局见 [DESIGN.md](../../DESIGN.md)。

左侧应用菜单处理工作区、会话、设置和维护。右侧猫标用于快速查看后台任务和回到原会话。两个入口都沿用 macOS 系统外观、键盘导航、VoiceOver 和当前语言。

## 左侧应用菜单

按 **Orca-Wails · 编辑 · 工作区 · 会话 · 窗口 · 帮助** 排列。下表按每栏实际显示顺序列出命令。

| 菜单 | 内容 |
| --- | --- |
| Orca-Wails | 关于 Orca-Wails（外壳与内核版本） ／ 设置… `⌘,`、桌面设置…、更新、内核维护 ／ 隐藏 Orca-Wails `⌘H`、隐藏其他 `⌥⌘H`、全部显示 ／ 退出 Orca-Wails `⌘Q` |
| 编辑 | 原生撤销、重做、剪切、复制、粘贴、全选等。由当前焦点决定哪些操作可用。 |
| 工作区 | 快速搜索… `⌘K`、新建工作区… `⌘N` ／ 上一个工作区 `⇧⌘↑`、下一个工作区 `⇧⌘↓`、最近工作区（最多 5 项） ／ 连接官方 Orca…、从官方 Orca 导入… |
| 会话 | 等待输入与受阻的会话，直接显示最多 3 项 ／ 新建 Agent 会话 `⌥⌘T`、新建终端 `⌘T` ／ 最近会话子菜单，最多 5 项 ／ 打开机器人 |
| 窗口 | 最小化 `⌘M`、进入／退出全屏 `⌃⌘F`、关闭 Orca 窗口 `⇧⌘W` ／ 将 Orca 窗口置前 |
| 帮助 | 键盘快捷键… ／ 打开配置文件、打开日志目录、打开数据目录 |

### 原托盘操作的去向

| 功能 | 左侧入口与反馈 |
| --- | --- |
| 开机启动、任务与应用通知 | 「Orca-Wails → 桌面设置…」。同页放通知声音、系统权限、请求权限或打开系统通知设置、发送测试通知。根据权限与开关状态启用对应项。 |
| 版本与更新 | 「Orca-Wails → 关于 Orca-Wails」显示外壳、内核和查询到的官方版本。「更新」子菜单提供应用检查或安装、可独立更新时的内核检查或安装，以及查询官方最新版本。检查结果和错误显示在原生窗口。 |
| 启动、重启、停止、回退内核 | 「Orca-Wails → 内核维护」。按当前状态显示启动或重启，有可回退版本时提供回退。随应用更新的内核沿用现有能力限制。 |
| 连接与迁移 | 「工作区 → 连接官方 Orca…／从官方 Orca 导入…」。导入前说明备份和重启影响。 |
| 机器人 | 「会话 → 打开机器人」。 |
| 关闭主窗、退出 | 「窗口 → 关闭 Orca 窗口」和「Orca-Wails → 退出 Orca-Wails」。 |
| 配置、日志、数据目录 | 「帮助」直接打开相应文件或目录。 |

会中断任务的维护动作沿用原生确认，说明影响，默认聚焦「取消」。动作完成后将结果显示在发起操作的窗口中，通知关闭时仍可看到结果。

## 右侧任务面板

- **一行工具栏。** 左边「当前／最近」，右边「打开 Orca」。打开时默认进入「当前」。右键原生菜单只显示「查看任务」和「打开 Orca」。
- **一张任务列表。** 等待输入、受阻排在前面，其后显示运行、监测或待确认的任务。每行显示标题、工作区、状态和时间。点任务直接打开原会话。最近页显示过去 24 小时内已结束的任务。无任务时显示空态，读取失败时就地提供「重试」。系统通知仍可直达原会话。
- **主窗口关闭时的入口。** 「打开 Orca」可唤回主窗口，冷启动成功时直接进入主界面。内核启动失败或 WebView 无法打开时，显示轻量原生状态窗口并激活左侧菜单，使用户仍能打开日志、桌面设置、内核维护或退出。执行「停止内核」后也显示该窗口，用户可在此重试打开主界面。

## 高频路径

- **回到待处理会话。** 点击「会话」，再点带有「等待输入」或「受阻」前缀的任务，直接定位原工作区和会话。先复用任务列表现有排序。任务超过 3 项时，在这组末尾显示「查看全部待处理会话…」，进入使用同一数据的完整列表。标题重名时附工作区名。暂无待办时省略该组，读取失败时显示不可用的状态提示。只读到部分工作区时提示范围，继续提供可定位的任务。
- **继续上次的工作。** `⌘K` 进入 Orca 现有搜索。「最近工作区」和「最近会话」按实际打开顺序记录，当前项可标记为选中。工作区或会话失效后从记录移除。同名项保留工作区或仓库信息，切换时按稳定标识定位。
- **开始新会话。** 菜单动作与 Orca 既有命令共用一个入口。新建 Agent 使用当前工作区和已配置的默认 Agent。当前工作区不可用或连接能力不足时禁用，禁止隐式换到其他工作区执行。
- **暂时收起窗口。** `⌘W` 继续由 Orca 处理当前标签页。`⇧⌘W` 是关闭主窗口的拟定键位，Core 和后台任务继续运行。`⌘Q` 结束应用和 Core。有活动任务时确认退出，焦点先放在「取消」。

## 接入与验收

1. 先扩展 `configureMenu()`，接入原生应用、编辑和窗口操作。把设置、通知、更新与维护界面接到左侧，复用 SwiftUI 设置视图及已有 Go 动作。会话菜单从已缓存的任务快照读取待办，点击时重新验证目标。菜单展开期间稳定项目位置和身份。
2. 再接入 Orca Web 端命令以及最近访问记录。仅在当前前台 WebView 已就绪且支持动作时启用对应命令。快捷键随实际生效的设置显示，并验证终端、编辑器、输入框焦点及自定义映射。候选 Core v1.4.268 的源码中 `⇧⌘O` 用于打开 Markdown 文件，也与宿主默认全局键位相同。本次菜单沿用宿主已有配置，接入时验证焦点分发，避免为菜单再注册相同按键。
3. 左侧入口可用后，收敛右侧面板与右键菜单。在 macOS 真机验证左右两侧的待办都能两次点击定位，关闭主窗口后任务仍运行，内核停止或启动失败时可从猫标进入左侧维护。覆盖权限拒绝、更新不可用、操作中断、长标题、VoiceOver 和深浅外观。上表按 Core 默认键位标注，接入时验证快捷键只触发一次。
