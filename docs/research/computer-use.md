# macOS Computer Use 调研

截至 2026-11-22，Orca 最新稳定版仍是 **v1.4.268**（`5dc5548`，MIT）。上游 `main` 的 `6d7915a` 与发布标签分叉，双方分别有 198 和 4 个独有提交。逐字节核对了两个版本的 Swift helper 入口、sidecar、CLI 实现与参数、CLI 文档和技能，六处内容一致。现有公开证据没有显示升级到 `main` 能改善 macOS Computer Use。 [稳定版](https://github.com/stablyai/orca/releases/tag/v1.4.268) · [分支对比](https://github.com/stablyai/orca/compare/v1.4.268...6d7915acf720b9afcd8ac9e7efc8d1d61e40b2a7) · [MIT 许可](https://github.com/stablyai/orca/blob/5dc5548/LICENSE)

**近期保留 Orca 驱动，优先做同机对照的候选是 agent-desktop 和 Cua Driver。** agent-desktop 保住 Wails 的 macOS 13.5 门槛，支持后台 AX 动作、独立光标和会话轨迹。Cua Driver 的会话反馈和批处理更完整，最低需 macOS 14。Agent S 的浮动活动面板适合参考如何显示审批与停止。Peekaboo 适合比较观察质量和动作验证。 [当前部署门槛](../../build/Info.plist#L14) · [agent-desktop 平台](https://agent-browser.dev/desktop/platforms/macos) · [Cua Driver 平台](https://cua.ai/docs/cua-driver/concepts/platform-support) · [Agent S for Mac](https://github.com/simular-ai/Agent-S/tree/main/app#this-mac)

## 慢在哪里，以及如何让过程可见

- **如果把隔离桌面纳入目标，优先对照 Cua。** Cua Driver 可用于本机，Lume 可在 Apple Silicon 上运行独立 macOS 或 Linux 来宾，Cua Spaces 展示实时桌面。Driver 与 Lume 使用 MIT，Spaces 界面使用 FSL-1.1-MIT。agent-desktop 也支持本机 macOS VM 和托管 Linux 微虚拟机。它的首台本机 VM 安装仍是实验功能，需手动完成来宾设置，之后可克隆并无头启动。两者的本机驱动时延仍需同机对照。 [Lume 快速开始](https://cua.ai/docs/lume/quickstart) · [Cua Spaces](https://github.com/trycua/cua/tree/main/apps/cua-spaces-macos) · [agent-desktop 沙盒](https://agent-browser.dev/desktop/sandboxes) · [macOS VM 设置](https://agent-browser.dev/desktop/sandboxes/macos)

- **先测现有路径。** 把同一任务拆成冷启动、AX 遍历、截图与编码、输入投递、结果验证、模型往返。Orca 为部分应用首次启用完整 AX 树时固定等 2.5 秒，AX 操作返回后若窗口状态没变还会继续观察约 1 秒。这些时间用于提高可靠性，也可能解释短操作的体感等待。原生 helper 在 macOS 14+ 优先用 ScreenCaptureKit，失败时回落 CoreGraphics。纯 AX 流程可用 `--no-screenshot`，需要像素时再比较 `--screenshot-max-edge`、`--screenshot-scale 1` 或 JPEG。 [AX 延迟观察与初始化](https://github.com/stablyai/orca/blob/5dc5548/native/computer-use-macos/Sources/OrcaComputerUseMacOS/main.swift#L394-L452) · [Swift 抓图实现](https://github.com/stablyai/orca/blob/5dc5548/native/computer-use-macos/Sources/OrcaComputerUseMacOS/main.swift#L3503) · [Orca 截图参数](https://github.com/stablyai/orca/blob/5dc5548/docs/site/content/docs/cli/computer-use.mdx#screenshots)
- **结果以独立状态为准。** 对同一 Apple Silicon 机器上的 AppKit、SwiftUI、Electron 和 WKWebView 分别测 AX 观察、文本输入或提交、遮挡窗口截图。记录冷启动和热路径 P50/P95、成功与失败耗时、错误窗口命中、用户前台焦点和指针是否变化。Orca 自带的公开 benchmark 比较的是 Linux/Windows 原生提供方与旧版 Cua Driver 0.38.0，明确排除了 macOS、CLI、sidecar 和模型，无法据此给出这里的速度排名。 [Orca benchmark 范围与测量合约](https://github.com/stablyai/orca/blob/5dc5548/config/benchmarks/computer-use/README.md)
- **让 Orca 界面订阅真实的会话事件。** 区分正在操作、等待模型与本轮结束，显示目标应用和动作类别。停止后拒绝后续动作，并把已投递的动作标为可能已经生效。现有菜单栏和会话视图可以共用事件。代理光标可选且避免挡住用户操作，做延迟对照时分别记录开启和关闭的结果。agent-desktop 明确说明后台动作会在取得交互租约前移动虚拟光标，动画时长会影响体感。权限入口可复用 `computer.permissionsStatus`，上游内置浏览器的 `active`、所属会话和虚拟指针事件也可用作参考。 [权限 RPC](https://github.com/stablyai/orca/blob/5dc5548/src/main/runtime/rpc/methods/computer/computer.ts#L54) · [浏览器活动事件](https://github.com/stablyai/orca/blob/5dc5548/src/shared/browser/automation/browser-agent-activity-contract.ts) · [agent-desktop 会话](https://agent-browser.dev/desktop/sessions)
- **网页任务按实际页面宿主路由。** 上游 Orca 的 `orca browser` 有按页定位、DOM/AX 快照、等待和效果返回，适合它所管理的页面。Wails 工作树的可见浏览器使用独立的 `WKWebView`，已有本地 DOM 接入代码。对照测试应单独验证命令是否操作了用户看到的同一个标签页。 [上游浏览器命令](https://github.com/stablyai/orca/blob/5dc5548/skill-guides/orca-cli/references/browser.md) · [Wails WKWebView 实现](../../native/macos/WorkspaceBrowser.h#L188)

本次没有安装候选实现，也没有做同机端到端测速。单独用 Orca 的 PNG 编码器处理合成图，2880 × 1800 输入平均约 143 ms，1440 × 900 约 31 ms，每项取五次。该测试只覆盖编码，真实任务还包含屏幕采集、应用响应、模型推理和工具调用。 [Orca 截图编码器](https://github.com/stablyai/orca/blob/5dc5548/native/computer-use-macos/Sources/OrcaComputerUseMacOSCore/ScreenshotEncoding.swift)
