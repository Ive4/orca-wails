# Orca macOS 菜单栏任务状态调研

当前菜单栏在猫标志旁显示运行或监测、等待输入、受阻三组灯。没有任务的组也占用位置。读取失败时，顶部的三个空心灯与空闲时相同，悬停提示会说明读取失败。点击猫标志可以打开任务面板。

## 产品参考

- **Carbon Copy Cloner** 用同一个菜单栏入口表示空闲、有任务运行、需要关注和任务已停用。点击进入 Dashboard 后可以看各任务的状态和操作。它和 Orca 一样需要概括多项后台任务，也要让用户能快速找到需要处理的那一项。 [CCC Dashboard 官方文档与图例](https://support.bombich.com/hc/en-us/articles/20686467217687-Monitoring-backup-tasks-with-the-CCC-Dashboard)
- **macOS 控制中心** 在固定图标旁一次只显示一个隐私指示圆点。摄像头与麦克风同时使用时，菜单栏显示绿色圆点，打开控制中心可以看到各项资源的使用情况。 [Apple 控制中心使用手册](https://support.apple.com/zh-cn/guide/mac-help/mchl50f94f8f/27/mac/27)
- **GitHub Desktop** 在分支名旁用一个徽标表示检查正在进行、通过或失败。点击旁边的 PR 编号可查具体检查。官方截图展示了失败徽标和展开后的明细。 [GitHub Desktop 检查状态文档与截图](https://docs.github.com/en/desktop/working-with-your-remote-repository-on-github-or-github-enterprise/viewing-and-re-running-checks-in-github-desktop)

## 方案对照

**建议用猫标志加单角标。** 空闲时只显示猫。运行或监测时加蓝点，等待输入时显示琥珀色省略号，受阻时显示红色感叹号，读取失败时显示灰色问号。红、黄、蓝按受阻、等待、运行的优先级选一个显示。用形状辅助识别颜色，角标随状态变化时保持同一位置，建议用静态显示。

例如，3 项运行、2 项等待输入、1 项受阻时，菜单栏显示红色感叹号。打开任务面板后显示三类数量和任务，用户可以直接点进对应会话。只读到了部分工作区时，明细提示统计范围。如果部分结果里没有已知活动，顶部仍用灰色问号表示状态未确认。

**三段环适合需要同时扫到并行状态的情况。** 在猫标志旁用一个环表示三个类别，蓝色在下、琥珀色在右、红色在左。某类有任务就点亮对应弧段。环上的位置固定，弧段表示是否有任务，数量放在面板里。用户一眼可以确认哪些类别同时存在，但更小的弧段和位置需要熟悉后才能快速辨认。

单角标把菜单栏的空间留给最需要关注的信号。它的取舍是同一时刻的其他状态需要点开查看。三段环保留这些信号的可见性，适合把菜单栏当作持续监看的入口。
